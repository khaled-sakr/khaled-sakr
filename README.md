### About me

I'm a **Full-Stack Software Engineer** working across **web, mobile, and backend development**, with a strong interest in **AI-powered applications**, **UI/UX design**, **design systems**, and **system architecture**.

I enjoy owning features end to end: shaping the user experience, building interfaces, implementing backend services, integrating APIs, and bringing working products to life.

My work also includes exploring **AI agents, intelligent workflows, and automation** to solve practical problems and make products more useful.

### What I work on

- **Full-stack products:** Web applications, backend APIs, SaaS features, and integrations.
- **Mobile experiences:** Cross-platform applications and thoughtful user journeys.
- **AI & automation:** AI-assisted workflows, agents, and integrations with intelligent services.
- **UI/UX & design systems:** Designing interfaces and building consistent, reusable component systems.
- **System design:** Thinking through architecture, reliability, integrations, and end-to-end product flows.
